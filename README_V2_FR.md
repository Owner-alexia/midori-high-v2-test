# Installation rapide

1. Ne supprimez pas l'ancien dépôt ou projet Supabase.
2. Exécutez `INSTALLATION_V2_SQL.sql` dans le SQL Editor du nouveau projet Supabase V2.
3. Publiez le contenu de ce dossier sur une branche de test GitHub Pages.
4. Connectez-vous avec l'adresse réelle Supabase Auth du compte administrateur.
5. Testez classes, matières, profils, notes, présences, devoirs et registre WL avant de remplacer le site public.

Le paquet n'a pas été testé contre le Supabase distant. N'utilisez pas de clé secrète/service_role dans `config.js`.
